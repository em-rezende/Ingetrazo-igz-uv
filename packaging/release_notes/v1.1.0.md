# igz-UV 1.1.0

Maintenance and organisation release: the extension is now a proper Python
package, and the user interface reaches seven languages. The UV algorithms
are unchanged (same results as 1.0.0).

## What changed

### Modular package
The single `igz-UV.py` module became a package with one responsibility per
file, which makes the code easier to read, test and extend:

```
igz-uv/
├── __init__.py       entry point (setup), version and i18n loader
└── core/
    ├── math_utils.py     pure geometry (vectors, cross, length, …)
    ├── texture.py        face UV model (texture, uvw, UV grid)
    ├── transforms.py     affine UV transform composition
    ├── mappings.py       the six projections
    ├── triangulate.py    triangulation preserving UVs
    ├── keyboard_tool.py  UVTransformTool (keyboard interaction)
    ├── panel.py          UVAdjustPanel (sliders)
    └── toolbar.py        toolbar, menu and panel attachment
```

### Seven interface languages
German (`de`), French (`fr`) and Chinese (`zh`) joined English (source),
Brazilian Portuguese (`pt-BR`), Spanish (`es`) and Italian (`it`). The
language is looked up from the files present in `i18n/` (exact tag first,
then the base language), falling back to English — a missing translation
never breaks the UI. Adding a language is still just a JSON file.

### Panel behaviour
The **Adjust UV** panel is registered with the host API (`app.add_panel`),
so it also appears in **Window ▸ Panels**, and it gets its tab icon from
`uv_panel_tab.svg` (dark/light theme aware). Its toolbar button is a
three-state toggle: show the panel, bring it to the front when it is
hidden behind another tab, hide it when it is in front.

## Features (unchanged)

- **Six projections:** planar, spherical, cylindrical, box, quad face, tube.
- **Interactive UV transform:** arrows move U/V, `Shift`+arrows scale,
  `Ctrl`+arrows rotate.
- **Adjust UV panel:** U, V, rotation and anisotropic Scale U / Scale V with
  live spin boxes, `Reset` and `Apply`.
- **Triangulate** keeping the texture identical.
- **Automatic UV grid** (`texture_grid.jpg`) for faces without a texture.

## Install

Copy the `igz-uv` folder into your IngeTrazo user plugin directory
(**Extensions ▸ Open plugins folder**), or install `igz-uv.zip` from the
extension catalog. Requires IngeTrazo 0.5.7 or newer (`app.add_panel`).
