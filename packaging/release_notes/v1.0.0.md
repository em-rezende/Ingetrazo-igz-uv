# igz-UV 1.0.0

First public release of **igz-UV**, a UV mapping extension for
[IngeTrazo](https://github.com/ingelibre/ingetrazo), inspired by classic
UV mapping tools, adapted for IngeTrazo.

## Features

### Six projection mappings
- **Planar Map** — projects along the current view direction (camera-aligned).
- **Spherical Map** — wraps UVs around a sphere centred on the selection.
- **Cylindrical Map** — wraps UVs around a world-Z-aligned cylinder.
- **Box Map** — assigns each face to its dominant plane (top / side / front).
- **Quad Face Map** — maps four-vertex faces to the (0,0)–(1,1) square.
- **Tube Map** — walks an ordered face chain, advancing U along the perimeter.

### Interactive UV Transform (keyboard)
Arrow keys move U/V (±0.05), `Shift`+arrows scale (±5%), `Ctrl`+arrows rotate
(±1°). The Value Control Box accepts a rotation angle (−180…180) or a uniform
scale factor.

### Adjust UV side panel
Five sliders — U, V, rotation and **anisotropic** Scale U / Scale V — transform
the **whole selection at once** around the common UV centre, with live spin
boxes. `Reset` restores the snapshot; `Apply` promotes the current state.

### Triangulate
Splits each selected polygon into a fan of triangles, keeping the texture
identical after the cut.

### Automatic UV grid
Faces without a texture get the built-in `texture_grid.jpg`, so the mapping is
visible immediately.

### Internationalisation
Interface in English (source), Brazilian Portuguese, Spanish and Italian. A new
language is a JSON file in `i18n/` — no Python needed.

## Install
Copy the `igz-UV` folder into your IngeTrazo user plugin directory
(**Extensions ▸ Open plugins folder**), or install `igz-uv.zip` from the
extension catalog. Requires IngeTrazo 0.x (API_VERSION 2).
